# EXPERIENCE — QUIROZ

Demo conceptual de una marca de experiencias digitales personalizadas para regalos, recuerdos, vínculos y aficiones.

## Probar la demo

Abre `index.html` con un servidor local. La experiencia no necesita dependencias ni proceso de compilación.

## Estructura

- `index.html`: contenido, semántica y SEO base.
- `styles.css`: dirección visual, responsive y movimiento.
- `app.js`: intro, selector de experiencias, latido sonoro y modal interactivo.
- `experiencia-osasuna.html`: ejemplo completo de una experiencia rojilla ficticia ambientada en Pamplona.
- `osasuna.css` y `osasuna.js`: dirección visual, intro, audio y narrativa del ejemplo.
- `assets/osasuna-demo/`: imágenes ficticias optimizadas, escudo y cántico de la demostración.
- `experiencia-cumpleanos.html`: experiencia completa de cumpleaños con recuerdos, mensajes, razones y deseo interactivo.
- `cumpleanos.css`, `cumpleanos.js` y `assets/cumple-demo/`: identidad y recursos del ejemplo de cumpleaños.

La demo evita datos personales y materiales reales de clientes. Cada contenido mostrado es conceptual.
